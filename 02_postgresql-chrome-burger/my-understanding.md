PostgreSQL คือ ระบบจัดการฐานข้อมูล (Database) ชนิดหนึ่งที่เก็บข้อมูลในรูปแบบ "ตาราง" (Table) ที่มีความสัมพันธ์กัน ซึ่งเราเรียกว่า Relational Database
Frontend: คือหน้าตาเว็บที่
เห็นBackend: คือสมองที่คอยประมวลผล
PostgreSQL: คือ "โกดังเก็บข้อมูล" ที่ Backend จะมาหยิบไปใช้หรือเอามาฝากไว้

จุดเด่นของ PostgreSQL
เป็นระเบียบมาก: ข้อมูลจะถูกเก็บเป็นแถว (Row) และคอลัมน์ (Column) เหมือน Excel ทำให้จัดการข้อมูลจำนวนมากได้อย่างแม่นยำ

Schema: เปรียบเสมือน "พิมพ์เขียว" หรือการวางโครงสร้างว่าในฐานข้อมูลนี้จะมีตารางอะไรบ้าง แต่ละตารางเก็บอะไร
Query: คือ "การส่งคำสั่ง" ไปถามฐานข้อมูล เช่น "ขอข้อมูลลูกค้าที่ชื่อสมชายหน่อย"
Primary Key: คือ "ID เฉพาะตัว" ของข้อมูลในแถวนั้นๆ (เหมือนเลขบัตรประชาชนที่ห้ามซ้ำกัน)
Foreign Key: คือ "ตัวเชื่อม" ที่บอกว่าข้อมูลในตารางนี้ ไปเกี่ยวข้องกับตารางไหน (เช่น รหัสลูกค้าในตารางคำสั่งซื้อ)

การทำงาน การจะเริ่มทำโปรเจกต์หนึ่ง เช่น ร้านขายของออนไลน์
Design ออกแบบตาราง (เช่น ตารางสินค้า, ตารางลูกค้า, ตารางคำสั่งซื้อ)
Deploy นำฐานข้อมูลไปไว้บน Cloud เช่น Aiven.io เพื่อให้เว็บเข้าถึงได้ตลอดเวลา
CRUD เริ่มเขียนโปรแกรมเพื่อ
Create เพิ่มสินค้าใหม่
Read ดึงรายการสินค้ามาแสดงบนหน้าเว็บ
Update แก้ไขราคาหรือสต็อกสินค้า
Delete ลบสินค้าที่เลิกขาย
