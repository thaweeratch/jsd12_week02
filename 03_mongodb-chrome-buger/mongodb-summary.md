MongoDB คื ระบบจัดการฐานข้อมูลประเภท NoSQL ที่เก็บข้อมูลแบบ Document-based Database
การเก็บข้อมูล: ไม่ได้เก็บเป็นตาราง (Table) ที่มีแถวและคอลัมน์เหมือน SQL แต่เก็บข้อมูลในรูปแบบที่คล้ายกับไฟล์ JSON (ใน MongoDB เรียกว่า BSON) ซึ่งข้อมูลแต่ละชุดจะถูกเรียกว่า "Document" และเก็บรวมกันใน "Collection"
ภาษาที่ใช้: ใช้ภาษา MQL (MongoDB Query Language) ในการจัดการข้อมูลแทนการใช้ SQL

โครงสร้างภายใน
Database: ตัวฐานข้อมูลใหญ่
Collection: เปรียบได้กับ Table (ตาราง) เป็นที่รวมของเอกสารประเภทเดียวกัน
Document: เปรียบได้กับ Row (แถว) คือข้อมูล 1 ชุด (เช่น ข้อมูลลูกค้า 1 คน)
Field: เปรียบได้กับ Column (คอลัมน์) คือหัวข้อข้อมูล (เช่น ชื่อ, นามสกุล, อายุ)
